# Contributing to RepoReady

Thank you for helping improve RepoReady. The project is intentionally small and dependency-light so that contributors can understand the full flow quickly.

Before opening a pull request, run `python -m pytest` and `python -m repoready.cli .`. Please include a focused test for behavior changes. Avoid adding network calls, hidden telemetry, or commands that execute arbitrary repository content.

Issues describing a reproducible problem, an example repository, and the expected behavior are especially useful.
